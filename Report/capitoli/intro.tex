The following report contains the work on the final assignment of the students Alessandro Rossi 256240 and Lorenzo Franco 257585.

\noindent The focus of the project A is to learn an approximate value function that can be then used as terminal cost in an MPC formulation. To achieve this, students are required to train their own neural network.

\noindent Contrary to the previous homework, where the assignment was structured as a tutorial (by guiding the students step by step through a pre-written code), the final project requires implementing the neural network almost from scratch.

\noindent As suggested in the assignment description, the project has been developed previously for a single pendulum system. After completion and testing, the code has been adapted to work with a double pendulum system. The single pendulum will not be discussed in the following, as it is qualitatively similar to the double pendulum case. The following report is structured in the three main phases of the project development: Dataset Generation, Neural Network Training and MPCs Comparison. A final conclusion section summarizes the results obtained and suggests possible future developments.
