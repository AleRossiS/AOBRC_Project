# guida_FDM
In questa repository trovate il documento latex della guida alla FDM che ho creato. La struttura è organizzata in diversi file: frontespizio.sty e la folder impaginazione contengono i pacchetti utilizzati e formattano il documento di testo. Il file main.tex organizza la struttura del documento e richiama tutti i file contenenti i paragrafi dei capitoli. Infine, una cartella contiene tutte le immagini. 

Il documento finale è in main.pdf.

Personalmente, ho lavorato su VSCode, il settaggio può essere leggermente complesso, ma una volta effettuato risulta molto comodo grazie anche alle estensioni che sono fornite. (Come copilot) Infine, è possibile lavorare direttamente su repository git da VSCode, come sto facendo ora.

Vi sono una molteplicità di guide online per come settare latex in VSCode.

La struttura può sembrare complessa all'inizio, ma permette di lavorare più ordinatamente al documento. Probabilmente saranno presenti alcuni errori o esistevano soluzioni più intelligenti per alcune problematiche che sono state riscontrate, ma mi affido ai successori a cui lascerò in affidamento questo documento.
